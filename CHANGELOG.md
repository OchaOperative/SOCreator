# \# Changelog

All notable changes to the package will be documented in this file.

# \[1.1.0]

### Added +

* 'Duplicate Class' menu item to allow cloning of scripts without definition conflict.
* 'Create Subclass' menu item to allow creation of a concrete class.

# \[1.0.1]

### Modified ~

* Updated assembly definition asset to prevent editor trying to build the package.

# \[1.0.0]

### Added +

* SOCreator script for instantiating individual ScriptableObjects in the project window without the use of the CreateAssetMenu attribute.
